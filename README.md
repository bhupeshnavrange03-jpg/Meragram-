# 🎨 MeraGram - Share Your Vibe

A modern, mobile-first social media app built for Android with Jetpack Compose. Create accounts, share posts, like content, search users, and connect with others—all locally without external APIs!

## ✨ Features

✅ **Welcome Screen** - Beautiful onboarding  
✅ **Authentication** - Local signup & login  
✅ **Home Feed** - Posts with stories section  
✅ **Like Posts** - Interactive engagement  
✅ **Search** - Find users & posts  
✅ **Create Posts** - Share your moments  
✅ **Notifications** - Stay updated  
✅ **Profile** - View user info & posts  
✅ **Bottom Navigation** - Smooth screen navigation  

## 🛠️ Tech Stack

- **Language**: Kotlin
- **UI**: Jetpack Compose
- **Architecture**: MVVM + Repository Pattern
- **Navigation**: Jetpack Navigation Compose
- **State Management**: StateFlow + ViewModel

## 📦 Installation

1. Clone the repository
2. Open in Android Studio
3. Build & Run on device/emulator

## 🚀 How to Use

1. **Welcome Screen** → Click "Sign Up" or "Login"
2. **Sign Up** → Create account with details
3. **Home** → View feed with posts & stories
4. **Like Posts** → Click heart icon
5. **Search** → Find users & posts
6. **Create** → Share new posts
7. **Notifications** → Check updates
8. **Profile** → View your info & posts
